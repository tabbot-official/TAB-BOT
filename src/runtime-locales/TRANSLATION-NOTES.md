# Runtime translation notes

All translations are model-authored and not native-certified. Exact schema, repeated placeholders and typed command names/action tokens are checked. This is separate from the core164-key schema. Missing runtime files use English fallback; a registered code or core dictionary does not imply runtime coverage.

Worker register notes:
- por: Brazilian Portuguese.
- srp: Latin script, ekavian. bos: ijekavian.
- jav: informal ngoko.
- heb: informal masculine singular.
- ara: neutral friendly Arabic, no regional dialect claim.
- uzb: Latin script. pan: Gurmukhi. nep: Devanagari.
- bel, hye, pol, ukr, jav, ceb, mkd, sqi: optional native skim recommended by authors.

English joke, fact, quiz/word corpora remain unchanged. User-supplied text and names are not translated. Technical tokens can intentionally equal English.

Final local runtime coverage:69 non-English dictionaries plus English,228 keys each. Seven core-translated languages use runtime English fallback: eus sin khm sna kin tat bak. Each was skipped in two confidence rounds. gle/cym are good-faith translations with uncertain idiom/mutations; native skim recommended.
